**QuantumFusion** is an end-to-end quantum-classical digital twin for real-time magnetic confinement stability in nuclear fusion tokamaks (ITER / SPARC class). By mapping non-linear magnetohydrodynamic (MHD) tearing modes to a fully-connected Ising spin Hamiltonian, the system leverages **IonQ's native trapped-ion all-to-all connectivity** to execute QAOA (Quantum Approximate Optimization Algorithm) circuits with **zero SWAP routing overhead** and a **$4.33\times$ reduction in circuit depth** compared to planar superconducting architectures.

---

## 1. Problem Statement: Tokamak Plasma Disruptions

In magnetic confinement fusion reactors, high-temperature plasma ($> 10^8\text{ K}$) must be isolated from the reactor vacuum vessel first wall. Non-linear resonant tearing modes ($m=2, n=1$ magnetic islands at safety factor $q=2$) introduce stochastic magnetic flutter, leading to catastrophic thermal quench and structural disruption (up to $42\text{ MJ}$ heat load on divertor targets).

External Resonant Magnetic Perturbation (RMP) coils trim the boundary flux. However, determining optimal discrete coil polarity vectors $s \in \{-1, +1\}^N$ across high-frequency drift timescales poses an **NP-hard combinatorial optimization challenge** where classical gradient-descent and PID loops get trapped in local energy minima.

## 2. Theoretical Formulation & Ising Mapping

### 2.1 Biot-Savart Coupling Kernel
The vacuum magnetic field generated by $N=8$ external toroidal correction coils at any spatial boundary point $\mathbf{r}$ is governed by the Biot-Savart law:
$$\mathbf{B}_m(\mathbf{r}) = \frac{\mu_0 I_m}{4\pi} \oint_{C_m} \frac{d\mathbf{l} \times (\mathbf{r} - \mathbf{r}')}{|\mathbf{r} - \mathbf{r}'|^3}$$

Minimizing residual normal magnetic flux leakage through the rational boundary surface $\mathcal{S}$ yields the objective function:
$$\min_{s} \mathcal{F}(s) = \int_{\mathcal{S}} \left| \sum_{m=1}^N s_m \mathbf{B}_m(\mathbf{r}) + \mathbf{B}_{\text{pert}}(\mathbf{r}) \right|^2 d\mathcal{S}$$

### 2.2 Dense Ising Hamiltonian
Expanding the surface integral translates the physical magnetic constraint directly into an all-to-all Ising Hamiltonian:
$$H_P = \sum_{m=1}^N \sum_{k > m}^N J_{mk} Z_m Z_k + \sum_{m=1}^N h_m Z_m$$
where:
* $J_{mk} = \int_{\mathcal{S}} \mathbf{B}_m(\mathbf{r}) \cdot \mathbf{B}_k(\mathbf{r}) \, d\mathcal{S}$ is the dense mutual coupling tensor.
* $h_m = \int_{\mathcal{S}} \mathbf{B}_m(\mathbf{r}) \cdot \mathbf{B}_{\text{pert}}(\mathbf{r}) \, d\mathcal{S}$ represents local mode disturbance projections.
* $Z_m \in \{-1, +1\}$ denotes the discrete current polarity of coil $m$.

## 3. Hardware-Algorithm Co-Design: Why IonQ Trapped-Ion?

Because magnetic induction couples every coil to every other coil, the coupling matrix $J_{mk}$ is strictly **dense (all-to-all)**.

* **Superconducting Grid / Heavy-Hex (IBM, Google):** Physical qubits feature only nearest-neighbor couplings. Routing 28 dense two-qubit interactions requires long cascades of routing gates, inflating circuit depth to $> 100$ and exceeding quantum coherence times ($T_2$).
* **IonQ Trapped-Ion Registers ($^{171}\text{Yb}^+$):** A linear chain of trapped ions in an RF Paul trap communicates via collective motional modes. Focused Raman lasers execute native pairwise Mølmer-Sørensen gates ($\text{R}_{ZZ}$) between **arbitrary ion pairs with zero SWAP penalty**.

```
    QAOA Ansatz Architecture (Depth: 24, SWAPs: 0)

    |0⟩ -[ H ]----•------------•--------------------[ Rx(2β) ]-[ M ]
                  |            |
    |0⟩ -[ H ]----Z(2γJ₀₁)-----|--------------------[ Rx(2β) ]-[ M ]
                               |
    |0⟩ -[ H ]-----------------Z(2γJ₀₂)-------------[ Rx(2β) ]-[ M ]
       ...
    |0⟩ -[ H ]--------------------------------------[ Rx(2β) ]-[ M ]
```

Verified using `Qiskit 1.x` optimization level 3 across realistic QPU topology coupling maps ($N=8$ qubits, $p=1$ QAOA layer):

| Architecture Topology | Qubits | Circuit Depth | 2Q Gates ($R_{ZZ}/\text{CX}$) | Total Gates | SWAPs (Direct) |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **IonQ Aria-1 (Trapped-Ion All-to-All)** | **8** | **24** | **28** | **84** | **0** |
| **Linear Chain (Nearest-Neighbor)** | 8 | 104 | 81 | 327 | 0* |

*\*Note: Level 3 transpilation decomposes routing permutations into CX cascades ($81$ and $70$ two-qubit gates vs. $28$ on IonQ), inflating depth by up to $4.33\times$.*

> **Key Finding:** IonQ trapped-ion hardware achieves a **$4.33\times$ reduction in circuit depth** and completely eliminates SWAP routing overhead, preserving gate fidelity well above the fault-tolerance threshold ($F > 99.4\%$).

## 5. Interactive 3D Digital Twin Features

The web frontend (`index.html`) operates as an interactive research simulator:
* **Biot-Savart Force Feedback:** Modifying discrete polarities ($C_0, \dots, C_7$) dynamically alters local magnetic pressure and toroidal particle trajectories at 60 FPS.
* **3D Coil Drag-and-Drop:** Physically displace any magnetic coil in 3D space to simulate structural misalignment; observe plasma boundary ballooning and trigger real-time QAOA asymmetric fault recovery.
* **Toroidal Cutaway (Slicer):** Continuously slice the vessel cross-section ($0^\circ - 180^\circ$) to examine core flux surfaces.
* **Virtual Langmuir Probe:** Click anywhere on the plasma manifold to inspect localized electron temperature ($T_e$), magnetic flux density ($B$), and residual field perturbation ($\delta B / B$).
* **Circuit Synchronization:** Interactive hover inspection across circuit qubits highlights corresponding all-to-all laser coupling vectors in 3D.

## 7. Quick Start & Verification

### 7.1 Clone and Environment Setup
```bash
git clone https://github.com/<your-username>/QuantumFusion.git
cd QuantumFusion
python -m venv venv
source venv/bin/activate  # Windows: .\venv\Scripts\activate
pip install -r requirements.txt
```

### 7.2 Run Transpilation Benchmark
Verify the hardware topology advantage on your local terminal:
```bash
python -m src.benchmark.transpiler_bench
```

### 7.3 Run Physical & Mathematical Tests
```bash
python -m unittest discover tests
```

### 7.4 Launch Interactive 3D Simulator
* **Option A (Direct Browser):** Open `index.html` in Chrome / Edge.
* **Option B (Streamlit Core):** Run `streamlit run app/main.py`.
